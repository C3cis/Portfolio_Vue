# 💻 Meu Portfólio Pessoal

Repositório do meu portfólio web, criado para apresentar meus projetos, habilidades e trajetória como desenvolvedora.

> **Destaque:** Este foi o meu **primeiro projeto desenvolvido com Vue.js**, criado para colocar em prática os conceitos de reatividade, componentes e gerenciamento de estado do ecossistema Vue.

---

### 🛠️ Tecnologias Utilizadas
- **Vue.js** (Framework Frontend)
- **JavaScript / TypeScript**
- **HTML5 & CSS3 / Tailwind CSS**

---

### 🎯 Principais Aprendizados
- Estruturação e reutilização de componentes no Vue.
- Construção de uma interface responsiva e acessível.
